# Data post-processing — coming soon (v2)

The post-processing stage of AuRA (object segmentation and dense tracking of the
recorded interaction, 3-D lifting, controller trajectories derived from the
recorded robot states and calibrated fingertip geometry, and registration of the
pre-interaction priors into the first interaction frame) will be released in v2.

v1 (this release) covers automated data collection only. The robot-executed
recordings it produces are the input of this stage; their on-disk format is
documented in [`../../docs/data_format.md`](../../docs/data_format.md).
